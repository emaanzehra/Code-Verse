## ✦ What is CodeVerse?

**CodeVerse** is the official e-learning platform of the **Department of Computer Science, UIT University, Karachi**. Students get structured access to high-quality video lectures across the most in-demand programming languages and frameworks, interactive quizzes, curated study tips, and energetic audio tracks — all in a cinematic, motion-rich single-page application.

```
Single file  ·  Zero dependencies  ·  Zero frameworks  ·  ~125KB  ·  ~1600 lines
```

## 🎮 User Modes

CodeVerse has three states. Each controls exactly what content is visible and which UI elements appear.

```
┌──────────────────────────────────────────────────────────────────────┐
│                        USER STATE MACHINE                            │
├──────────────┬──────────────────────┬────────────────────────────────┤
│  STATE       │  VIDEO ACCESS        │  AUDIO / EXTRA FEATURES        │
├──────────────┼──────────────────────┼────────────────────────────────┤
│  Default     │  4 guest videos      │  3 audio tracks                │
│  Guest Mode  │  4 guest videos      │  3 audio tracks + lock banner  │
│  Registered  │  All 10 unlocked     │  All 8 tracks + Quizzes + Tips │
│  Signed Back │  All 10 restored     │  Full session restored         │
└──────────────┴──────────────────────┴────────────────────────────────┘

State Transitions
─────────────────
  Any     ──→  Guest       "Continue as Guest" (hero / nav)
  Any     ──→  Register    "Register Free" → fill form → submit
  Any     ──→  Sign In     "Sign In" (nav / modal tab) → email + password
  Reg/SI  ──→  Signed Out  Profile dropdown → "Sign Out"
```

### 🔐 Sign In Flow
1. Click **Sign In** in the nav bar — modal opens directly on the Sign In tab
2. Enter the **email and password** used during registration
3. On success → full session restored (profile, videos, audio, quizzes)
4. Wrong credentials → red error banner + field highlight + retryable

### ✦ Register Flow
1. Click **Register Free** (nav, hero, lock banners, benefits card)
2. Fill in: name · email · phone · DOB · student ID · program · photo · password
3. On submit → credentials stored in memory · full library unlocked · profile populated

## 🧠 Quiz System

50 questions across 10 topics. Each quiz has 5 multiple-choice questions with 4 options. All questions are sourced directly from the corresponding video lecture content.

| Quiz | Topic | Based On |
|:-----|:------|:---------|
| 🐍 Python | Variables, lists, functions, comprehensions | Python Full Course |
| 🌐 HTML5 | Semantic tags, forms, attributes, accessibility | HTML5 & Web Dev |
| 🧠 CS | Big-O, data structures, algorithms, RAM | CS Fundamentals |
| ⚡ JavaScript | const/let, closures, typeof, array methods | JavaScript Course |
| ⚛️ React | useState, useEffect, props, keys, JSX | React JS Course |
| 🟢 Node.js | Express, REST methods, middleware, require() | Node.js Course |
| 🔀 Git | git add, clone, stash, log, pull requests | Git & GitHub |
| 🤖 ML | Supervised learning, overfitting, scikit-learn | ML for Beginners |
| 🗄️ SQL | WHERE vs HAVING, JOINs, PRIMARY KEY, COUNT() | SQL Course |
| 🎨 CSS | Box model, flexbox vs grid, z-index, position | CSS Course |

**Quiz features:**
- Instant colour feedback — ✅ lime green = correct, ❌ coral red = wrong
- Correct answer always reveals itself after selection
- Explanation panel slides open beneath each answered question
- Live score badge updates in real time (Score: 3 / 5)
- Retake button resets the full quiz cleanly

## 💡 Pro Tips

One power tip per topic — each distilled from the lecture content for immediate practical use.

| Topic | Tip |
|:------|:----|
| 🐍 Python | Use list comprehensions — cleaner and faster than loops |
| 🌐 HTML5 | Use semantic tags (`<nav>`, `<article>`) over generic divs |
| 🧠 CS | Always ask "what's the time complexity?" — the interview habit |
| ⚡ JS | Default to `const`, use `let` only when needed, never `var` |
| ⚛️ React | One component = one responsibility. Split early. |
| 🟢 Node.js | Use `async/await` with `try/catch` — no callback hell |
| 🔀 Git | Atomic commits with conventional messages (`feat:`, `fix:`) |
| 🤖 ML | Always run EDA before modelling — garbage in, garbage out |
| 🗄️ SQL | Index `WHERE`, `JOIN`, and `ORDER BY` columns |
| 🎨 CSS | Flexbox for 1D layout, Grid for 2D — use the right tool |

## 🚀 Getting Started

```bash
# Option 1 — Direct (instant)
# Double-click portal.html — opens in your default browser

# Option 2 — Python local server (recommended — enables YouTube embeds)
python -m http.server 8000
# Visit: http://localhost:8000/portal.html

# Option 3 — Node.js
npx serve .

# Option 4 — VS Code Live Server
# Right-click portal.html → "Open with Live Server"
```

> **Why use a server?** YouTube blocks iframe embeds when opened via `file://` (browser security policy). Serve over HTTP and all 10 videos embed perfectly. The "▶ Watch on YouTube" fallback handles the `file://` case gracefully.

### Free Hosting Options

```bash
# GitHub Pages
git init && git add . && git commit -m "feat: initial codeverse"
git remote add origin https://github.com/USERNAME/codeverse.git
git push -u origin main
# Enable Pages: Settings → Pages → Deploy from branch: main

# Netlify (30 seconds)
# netlify.com → drag portal.html onto deploy zone → live URL instantly

# Vercel
npx vercel --prod
```

## 🛠️ Customisation Guide

### Changing Colours
All design tokens live in `:root` — change one, it propagates everywhere:
```css
:root {
    --lime:   #CAFF4C;  /* Primary: CTAs, cursor, quiz correct */
    --coral:  #FF5C5C;  /* Danger: errors, wrong answers, cursor hover */
    --sky:    #3DCCFF;  /* Sign In button, audio cards */
    --violet: #A855F7;  /* Ambient blobs, registered accents */
}
```

### Adding a New Video
Duplicate a `.video-card` block inside `#regVideos` (or `#guestVideos`) and update:
```html
<div class="video-card">
    <div class="video-tag" style="background:#HEX;color:#FFF;">🏷 LABEL</div>
    <div class="video-thumb-wrap">
        <iframe class="video-thumb"
            src="https://www.youtube.com/embed/VIDEO_ID"
            title="Title" allowfullscreen loading="lazy">
        </iframe>
        <div class="video-fallback">
            <div class="vf-icon">▶️</div>
            <p>Videos load when hosted on a server</p>
            <a href="https://www.youtube.com/watch?v=VIDEO_ID" target="_blank">
                ▶ Watch on YouTube
            </a>
        </div>
    </div>
    <div class="video-info">
        <h3>Title</h3><p>Description.</p>
        <div class="video-meta"><span>🕐 X hr</span><span>⭐ 4.X</span><span>👥 Level</span></div>
    </div>
</div>
```

### Adding a Quiz Topic
In the `QUIZZES` object in `<script>`, add a new key:
```js
your_topic: {
    qs: [
        {
            q: "Your question text?",
            opts: ["Option A", "Option B", "Option C", "Option D"],
            ans: 0,  // zero-indexed correct answer
            exp: "Explanation shown after answering."
        },
        // ... 4 more questions
    ]
}
```
Then add a tab button and panel in the HTML matching the key.

### Adding a Pro Tip
In the `.tips-grid`, duplicate a `.tip-card`:
```html
<div class="tip-card tip-py">   <!-- tip-py / tip-js / tip-web etc for colour -->
    <div class="tip-tag">🐍 Python</div>
    <span class="tip-icon">⚡</span>
    <h4>Your Tip Title</h4>
    <p>Explanation with optional <code>inline code</code> here.</p>
</div>
```

### Adjusting Sparkle Density
```js
// In <script> — find:
if (sparkleTimer % 3 === 0)    // default: every 3rd mouse-move

// Options:
if (sparkleTimer % 1 === 0)    // very dense
if (sparkleTimer % 6 === 0)    // minimal
```
